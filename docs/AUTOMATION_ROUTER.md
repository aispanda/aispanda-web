# Automation Router

Read before running or changing automation. Every maintained script must be registered here. Scripts may validate or build; they must not commit, push, deploy, spend money, change DNS/IAM, or handle secrets without explicit authority.

| Automation | Purpose | Inputs → outputs | Boundary | Verification |
|---|---|---|---|---|
| `scripts/validate-site-profile.mjs` | Fail clearly when required site-governance fields are absent | `site-profile.json` → pass/fail | Read-only; no external calls | `pnpm validate:profile` |
| `scripts/validate-content-boundary.mjs` | Block source or generated output containing prohibited source-project/third-party names | Repository or explicit build directory → pass/fail | Reads text-like project files; ignores dependencies and Git internals | `pnpm validate:content`; also runs after production build |
| `server/governance-contract.mjs` + `tests/fixtures/governance-contract-v2.json` | Deterministically validate `story-contract-v2`, governance versions, Linear state and actual Git runtime identity | Saved Linear issue + locally observed runtime fields → structured pass/fail gates and violation codes | Pure and read-only; no network, filesystem mutation or external writes | `pnpm test:governance` |
| `scripts/GovernanceToken.ps1` + `scripts/Initialize-GovernanceToken.ps1` | Persist the localhost governance key across shells without storing plaintext in Git | Cryptographically random key → process environment plus Windows CurrentUser DPAPI ciphertext under `%LOCALAPPDATA%` | Windows-only encrypted-at-rest fallback; environment override takes precedence; refuses rotation without `-Force`; plaintext is never printed or written to the repository | `pnpm test:governance` |
| `scripts/Start-GovernedTask.ps1` | Fail-closed local build-start gate for a governed Linear task | Task ID + locally observed Git root/origin/branch/HEAD → exact authenticated localhost n8n authorization request and structured pass/fail result | Reads local Git state; calls loopback n8n only and rejects redirects; token resolves from `N8N_GOVERNANCE_TOKEN` or the Windows-encrypted local fallback; does not edit code, commit, push, deploy, or execute a build command | `pnpm test:governance` |
| `scripts/Test-GovernanceBranchMismatch.ps1` | Prove that a real Linear task paired with the wrong local branch is denied | DPAPI/environment key + published localhost webhook → asserted HTTP 502 FAIL with `BRANCH_TASK_MISMATCH` | Read-only negative test; never prints the key and performs no Linear or repository write | Run against the active localhost workflow; no one-use test listener is required |
| `workflows/authorize-build-start.local.json` | Inactive Community Edition n8n configuration for the authenticated build-start decision | Local authenticated webhook + current read-only Linear issue + observed Git runtime identity → PASS, BLOCKED, REPLAN, or FAIL | Import inactive; bind only a local Header Auth credential and read-only Linear OAuth credential; runs on loopback and grants only `local_build_start`; no Cloud credential, AI, write, shell, deploy, or release action | `pnpm test:governance`; then the local endpoint test matrix |
| `scripts/sync-data-model-explorer.ps1` | Copy a verified public Data Model Explorer build into the site | Explicit source build → `public/labs/data-model-explorer/` | Generated public files only; source asset remains canonical | Script verifies `index.html`, fixed destination and subpath base |
| `scripts/sync-supportzero-case-workspace.ps1` | Copy the verified fictional SupportZero list workspace into the site | Explicit curated source build → `public/support-workspace/` | Static public projection only; no database, runtime API, source map, identity, UUID or local path | Script verifies `index.html`, relative asset paths, fixed destination and public boundary patterns |
| `pnpm build` | Validate profile and generate the static public site | Source/pages/profile → `dist/` | No deployment | Build must pass cleanly |
| `Dockerfile` + `nginx.conf` | Package generated static site for Cloud Run | Repository → port-8080 container | Does not create registry, IAM, service or deployment | Local container smoke test before release |
| Central Deployment Automation asset | Preflight, typed approval, Cloud Build, verification and handback | Project deployment profile → authorized Cloud Run release | Resolve through the owner's reusable-asset inventory; never run without the exact documented gate | Central toolkit tests plus project dry run |
